Pink Breaker PWA v10

構成
- index.html: 元版ゲーム本体をベースに、ステージ制作・保存・カスタムステージプレイを統合したメインアプリ
- classic-original.html: アップロードされた元版HTMLのバックアップ
- manifest.webmanifest / sw.js / icon.svg: PWA用ファイル

使い方
1. このフォルダ一式をHTTPS対応のWebサーバーへ配置してください。
2. index.htmlを開き、タイトル画面の「ステージ制作」から背景画像と1〜4枚のブロック画像を登録して保存します。
3. タイトル画面の「ステージ選択」から保存済みステージの「プレイ」を押すと、元版のゲームエンジンでブロック画像を順番にプレイします。
4. iPhoneではSafariで開き、共有メニューから「ホーム画面に追加」を選べます。

保存データについて
- ステージ画像はIndexedDBに端末内保存されます。ブラウザのサイトデータを消去すると失われる場合があります。
- PWAのService WorkerはHTTPS環境で動作します。file://で直接開いた場合はPWAのオフライン機能は有効になりません。
